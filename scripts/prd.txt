# Fooding - 냉장고 관리 앱

## 개요
사용자가 냉장고 속 식재료를 시각적으로 관리할 수 있는 모바일 앱

## 주요 기능

### 1. 냉장고 시뮬레이션
- 냉장고 그래픽을 통한 직관적인 UI 제공
- 냉장고 내부 구역(냉장실, 냉동실, 실온보관실 등)을 시각적으로 표현
- 각 구역 클릭 시 해당 위치에 식재료 추가 가능
- 냉장고 그래픽 내 위치를 클릭하면 해당 위치에 식재료 추가 가능
- 추가된 식재료는 선택한 위치에 시각적으로 표시
- 하단에 식재료 리스트로 정리되어 보여짐

### 2. 식재료 관리
- 식재료 추가/수정/삭제 기능
- 유통기한 알림 기능
- 카테고리별 분류 (과일/채소, 육류, 유제품 등)

### 3. 재고 현황
- 현재 보유한 식재료 목록 표시
- 유통기한이 임박한 식재료 우선 표시
- 소비기한 알림

## 사용자 인터페이스

### 1. 메인 화면
- 냉장고 3D 그래픽 표시
- 각 구역별로 클릭 가능한 영역 제공
- 하단에 현재 보유한 식재료 리스트 표시
- 식재료 추가 버튼

### 2. 식재료 추가 화면
- 식재료 이름 입력
- 카테고리 선택
- 유통기한 설정
- 수량 입력
- 보관 위치 선택 (냉장/냉동/실온)
- 냉장고 그래픽 내 위치 선택

### 3. 재고 현황 화면
- 카테고리별 정렬 기능
- 유통기한 순 정렬
- 검색 기능

## 기술 스택
- React Native
- React Navigation
- Redux (상태 관리)
- Firebase (백엔드)

## 향후 개선 사항
- 레시피 추천 기능 연동
- 바코드 스캔을 통한 자동 등록
- 클라우드 동기화
- AI를 활용한 유통기한 알림 최적화
